**Problem:** User asked: "Did checked if removing the annotation cleaning will not produce an infinity accumulation of annotations through the logs and your ramifications?"
**Solution:** Wrote `zzz_review_accum_test.go` proving that removing `clear()` does NOT cause implicit accumulation — sibling derivations and 1000-iteration ephemeral derivations both leave the parent unchanged. Result fed into final design (`make + copy` clone helper, not naive removal).
**Files:** scratch test deleted after run.

### 2.4 Implementation of user-selected items

**Problem:** User selected a subset of fixes via AskUserQuestion and authorized implementation.
**Solution:** All items below implemented and verified with `go build ./...`, `go vet ./...`, `go test ./... -count=1`, `go test -race ./... -count=1` — all green.

- **Close polish.** `errors.go` gained `ErrLoggerClosed` and `ErrNilTracer` sentinels. `logger.go` `Close` returns `ErrLoggerClosed` on second call; `log()` returns silently if closed; both `// TODO Improve it` removed; one-line doc on `Close` noting post-Close logs are no-ops.
- **(B) `With`/`Named` accumulate.** Deleted `clear()`. New `cloneAnnotations(src []Annotation) []Annotation` helper. `With` allocates `make([]Annotation, 0, len(l.annotations)+len(annotations))` then appends parent + new. `Named` clones existing annotations.
- **(C) Snapshot before hooks.** `logger.go` `log()` now sets `entry.Annotations = cloneAnnotations(l.annotations)`. `event.go` `Emit` uses `entry.Annotations = append(cloneAnnotations(e.annotations), e.errDetails...)`.
- **(D) `WithOutputs` refactor.** Private `resolvedOutputs []Output` field added to `Config`. `WithOutputs` no longer opens/closes files — mirrors only `Type`, `Format`, and `Path` (for `*fileOutput`) into `Outputs` for validation, stashes live outputs in `resolvedOutputs`. `BuildOutputs` short-circuits when `resolvedOutputs` is non-empty. Removed `"fmt"` import from `options.go`.
- **(E) CNPJ mask.** Changed mask from `**.***.***/**01-**` to `**.***.***/****-**` (was leaking literal `01`, an artifact of copy-paste from the doc example value `12.345.678/0001-90`). Updated tests, package doc, both READMEs, and the PII skill.
- **(F) `previous_hash` naming.** Doc comments `PrevHash` → `PreviousHash` in `hook.go:14` and `audit.go:270`. README audit field tables `prev_hash` → `previous_hash`. Runtime emission was already `previous_hash`; this was doc rot.
- **(G) `Metrics.HookDuration` collapse.** Removed `HookDurationWithError`; renamed the with-error variant to `HookDuration(ctx, name, dur, hasError bool)`. Updated `Metrics` interface, `NoopMetrics`, `otelMetrics`, the `HookChain.Process` call site in `hook.go`, `metrics_test.go`, both READMEs, and `plugin/docs/api-reference.md`. Breaking change (acceptable pre-1.0).
- **(A) Doc compilation fixes.** Replaced `&axio.HTTP{...}` inside `With(...)` with `axio.Annotate("http", axio.HTTP{...})` in 11 sites across `axio.go` (lines 84–93 and 268–272), `README.md` (lines 142, 402, 875, 909), `README.pt-BR.md` (lines 140, 349, 725, 759), and `plugin/agents/axio.md:118`.
- **(H) Examples.** `examples/basic/main.go:59` `"disk 90%% full"` → `"disk 90% full"` (`errors.New` doesn't format). Created `examples/config/config.yaml` (30 lines, minimal config with `serviceName`, `version`, `environment`, `level`, two outputs, rotation block).
- **`WithTracer(nil)`.** `options.go` now returns `ErrNilTracer` when `t == nil` (symmetric with `WithMetrics`).
- **Rotation `Close` sync.** `fileOutput` gained `rotationWG sync.WaitGroup`. `startTimeRotation` does `Add(1)` before goroutine, `defer Done()` inside. `Close` does `f.rotationWG.Wait()` after `close(f.done)` and before `f.lumberjack.Close()`. Added `"sync"` import to `output.go`.
