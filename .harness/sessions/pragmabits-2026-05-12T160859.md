### 2.2 Fork-Close fix (the bug from §2.1) — `isFork` flag

**Problem:** `*atomic.Bool closed` on the `*logger` struct was pointer-shared across all forked loggers produced by `Named`/`With` (because the methods have value receivers and the struct copy keeps the same pointer). Calling `Close()` on any forked child flipped the shared flag and tore down outputs the root still held open. Tests didn't cover close-on-fork so the bug was invisible.
**Solution:** Added `isFork bool` to `logger`, set it in `Named` and `With` before returning, added `ErrLoggerNotRoot` sentinel in `errors.go`, and made `Close()` return `ErrLoggerNotRoot` early when `isFork == true`. Added two tests: `TestLogger_CloseOnFork_DoesNotAffectRoot` and `TestLogger_CloseOnFork_DoesNotCloseSharedOutputs`. Updated `Logger.Close` interface doc and `logger.go` implementation doc.
**Files:** `errors.go`, `logger.go`, `review_followup_test.go`. Landed in commit `9a186b4`.
